# Hackathon Requirements

## 1. Official theme
AI Agents That Learn Using Hindsight.

Classification: Mandatory

## 2. Problem statement
Engineering teams repeatedly investigate similar production incidents without retaining verified operational learning. IncidentIQ solves this by giving the product a persistent, evidence-based memory system that learns from previous successes and failures.

Classification: Mandatory

## 3. Mandatory tools and platform requirements
- Hindsight integration required
- download and use Band AI Desktop during development
- public GitHub repository required
- functional application demonstration required
- live demo required

Classification: Mandatory

## 4. Hindsight requirements
- Hindsight is part of the product core, not an optional add-on
- the product must show real `retain()` and `recall()` behaviour
- the memory effect must be demonstrated visually and functionally
- the app must not pretend unverified memory is confirmed truth

Classification: Mandatory

## 5. Band AI Desktop requirement
Band AI Desktop must be downloaded and used during product development.

Classification: Mandatory

## 6. Judging criteria
- Innovation: 30%
- Hindsight Memory: 25%
- Technical Implementation: 20%
- UX: 15%
- Real-world Impact: 10%

Classification: Mandatory

## 7. Technical submission requirements
- public GitHub repository
- working product demo
- technical documentation
- clear demonstration of Hindsight memory behaviour

Classification: Mandatory

## 8. GitHub requirement
A public GitHub repository is required and should contain the actual project, documentation, and code artifacts.

Classification: Mandatory

## 9. Live demo requirement
- live product demo required
- show before-and-after memory effect
- demonstrate real retain/recall behaviour
- label synthetic data clearly

Classification: Mandatory

## 10. Individual article requirements
Each team member must publish their own article.

Requirements:
- title must mention Hindsight
- article body must not mention the hackathon
- article must explain the real implementation
- include architecture and code examples

Classification: Mandatory

## 11. LinkedIn requirements
Each team member must publish a LinkedIn post.

Requirements:
- max 800 characters
- include GitHub repository URL
- tag Code.in
- add article URL in first comment
- add Hindsight GitHub URL in another comment

Classification: Mandatory

## 12. Video requirements
One public YouTube video per team.

Requirements:
- 2–5 minute duration
- English content
- min 1080p resolution
- show actual `retain()` and `recall()` behaviour
- show before-and-after memory effect
- use real application behaviour
- clearly identify synthetic data

Classification: Mandatory

## 13. Content restrictions
- do not claim unimplemented functionality
- clearly label synthetic incident data
- do not mention hackathon in article body
- do not invent additional organiser requirements

Classification: Mandatory

## 14. Final submission checklist
- Hindsight integrated and functioning
- Band AI Desktop used during development
- public repository created
- functional demo ready
- live demo rehearsed
- each team member has article ready
- each team member has LinkedIn post ready
- YouTube video ready and compliant
- synthetic data clearly labeled

Classification: Mandatory

## 15. Optional improvements
These are recommended but not required:
- richer analytics panels
- expanded failure memory filters
- stronger memory conflict UX
- extra guided demo polish

Classification: Recommended

## 16. Summary
The mandatory items are the real product requirement: Hindsight must be the centre of the project, the product must be demonstrable, and all public-facing team content must be honest, compliant, and clearly identify synthetic data where used.
